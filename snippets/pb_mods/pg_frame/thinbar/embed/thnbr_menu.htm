TOP BAR EXTRA NAVIGATIONr:: Optional Extra Nav Links to stand out.

Splits into 2 sections (left and right on larger screens, top and bottom on smaller screens).

Change colors and sizes if other than site default is desired. All style settings may also be changed at element level.

TIP:

"Stick Bar To Top" should not be used if this option is used for the Navigation Menu (and vice versa).

"Stick Bar To Top" means the bar stays visible as user scrolls.

Format Section 1 Text

Style the text or leave default.

These settings only affect section 1 text (left side on larger screens, top on smaller screens)


First Section (left side on large screens, top side on smaller screens).

Add Font Awesome Icons, create a short title, then choose link. To link outside of this site, choose 'External'. For phone numbers or emails, put the phone number or email address inside the 'External Link' box.

Only top 3 will show on bar. Rearrange order by dragging rows as desired. "Add A Row" adds a new set.

IMPORTANT: full Font Awesome code. EX (no quotes): "fas fa-comments" or "fas fa-phone-volume" or "fa-solid fa-arrow-up-right-from-square". Find Font Awesome icon codes here. Leave blank if not needed.
